# Advance-Keylogger

This project is an Advance Keylogger designed for security auditing and system monitoring purposes. It goes beyond simple keystroke logging by incorporating multi-vector data collection, including visual snapshots, clipboard monitoring, and audio recording.

#Key Features
Multi-Input Capture: Records keyboard inputs, captures desktop snapshots, and monitors clipboard data for comprehensive activity tracking.
Advanced Monitoring: Includes microphone input recording to capture ambient audio and system information extraction for hardware/software profiling.
Automated Exfiltration: Features built-in email functionality to transmit captured data to a remote address for analysis.
Performance Optimized: Built for accuracy in data collection and minimal system impact during analysis.

#Technical Overview
The tool was developed as a professional portfolio project to demonstrate proficiency in Python scripting and security automation.

Language: Python.
Category: Cybersecurity / Monitoring Tool.
Primary Functions: Keystroke logging, Desktop screenshot capture, Clipboard data extraction, Microphone audio recording, System metadata collection, Automated email reporting.
